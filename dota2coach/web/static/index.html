Откройте dota2coach через локальный сервер

HTML-файл не является самостоятельной страницей: сервер добавляет переводы и подключает API. Запустите команду в папке проекта, затем откройте адрес ниже.

python -m dota2coach serve http://127.0.0.1:8000

Open dota2coach through the local server. The server injects translations and provides the API.

dota2coach
